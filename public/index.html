API Tokens

接口文档

外部服务用 Token 读写数据。鉴权方式二选一：请求头 X-API-Token: <TOKEN>，或 Authorization: Bearer <TOKEN>。

方法路径说明
GET/api/records读取全部数据（Token 可见所有记录）
GET/api/records/:id读取单条数据，:id 为记录 ID
POST/api/records创建数据
PUT/api/records/:id更新数据（可只传要改的字段）
DELETE/api/records/:id删除数据

请求示例

# 创建数据（data 为任意 JSON 值）
curl -X POST http://localhost:3000/api/records \
  -H "X-API-Token: <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"name":"示例","data":{"key":"value"},"anonymous_access":false}'

# 更新数据（:id 替换为记录 ID）
curl -X PUT http://localhost:3000/api/records/<ID> \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"data":{"key":"new value"}}'

# 删除数据
curl -X DELETE http://localhost:3000/api/records/<ID> \
  -H "X-API-Token: <TOKEN>"

创建记录必填 data；name 与 anonymous_access 可选。anonymous_access=true 时该记录无需登录即可读取。记录 ID 可在数据列表中查看并复制。
